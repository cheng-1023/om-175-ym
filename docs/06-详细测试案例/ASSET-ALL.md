# 详细测试案例文档 (Comprehensive Test Cases)

> 以下为 `docs/06-详细测试案例/ASSET-ALL.md`。它由 QA 在写代码前基于系统架构与需求输出，并在经过“三驾马车”联审后封版。在开发提测后，QA 将拿着全网最详尽的这份手册下深水区捉虫。

## 1. 验证范围描述
- **关联需求**：`docs/03-需求文档/ASSET-001 ~ 005.md`
- **关联架构**：`docs/04-系统设计/ASSET-ALL.md`
- **考点说明**：本卷包含了非公开给开发的深水区测试、极小概率破坏路径、非功能性测试及连带大范围回归牵引面。不打折扣地检查物理删除纯度与动态图谱解析的边界。

## 2. 跨模块全栈链路测试 (Integration & E2E)
> 偏离单接口，主要验证跨多个微服务、业务域时的数据流转和状态机更迭。

| 用例编号 | 场景特征 | Given (前序环境布置) | When (综合动作触发) | Then (断层与状态机预期) | 优先级 | 实机截图凭证要求 |
|:---|:---|:---|:---|:---|:---|:---|
| TC-INT-001 | [大流向闭环全穿透] | 两大独立职权的用户：Steward端和Consumer端协同 | 1. Steward建类型与必填属性，建目录群；2. Consumer发现该目录后进入关联注册数据资产并填写值；3. 换另一个Consumer进行ES高级树级检索。 | 业务全流转无阻涉。各角色均能在自身权限范畴内看见正确生效的 UI 数据及 Tab 展示。 | P0 | [终端消费角色查获精准ES列表快照] |
| TC-INT-002 | [高级检索之极限树形包罗] | 建立 A->B->C 深度分类长树，B/C层分批次挂靠了5个不同的数据资产 | 打开概览，在左侧目录树仅选中最根部父级"A" | 右侧数据列表及ES请求入参必须完整翻译囊括出下面那5条被深埋在B和C孙级别的孤立资产对象集合 | P0 | [包含查询体与五条正确召回数据的联播图] |

## 3. 深水区探索与破坏性测试 (Exploratory & Destructive)
> 放飞想象力，不再依赖 Happy Path。并发越权、各种超长字符、端云不同步、竞争条件。

| 用例编号 | 破坏特征 | Given | When (绕开正常限制的操作) | Then (安全防御或降级预期) | 优先级 | 实机截图凭证要求 |
|:---|:---|:---|:---|:---|:---|:---|
| TC-EXP-001 | [关系网死锁并发抢注] | 同时调起批量导入CSV与单点新建某一个资产目录的并发线程 | 对准同一个 Parent ID 的极速同频操作写入 | 事物解耦，最终只表现为目录同级别罗列，不能因锁抛500且不能产生无头孤儿行数据。 | P1 | [高并发测试脚本过关与事后数据库结果截图] |
| TC-EXP-002 | [ES数据异构化落后检测] | 截断或拉慢 DB->ES 的流转总线 | 编辑完一条数据资产的扩充属性后，强行以毫秒极差发起 Search 列表请求 | DB主导的数据表单保持修改，哪怕ES滞后1秒，端上展示的数据依然要呈现一致连贯不漂移。 | P1 | [日志证实ES落后而展现结果未受牵连的图证] |
| TC-EXP-003 | [强删遗存穿透验证] | [强行干预后台库] | 直接在DB使用 SQL 对某资产进行 `DELETE` | 回到前端页面查看曾点过赞的 Activity Feed (活动流)。系统必须做到无主引用的通知记录自动失活或者不触发阻断整个版面拉取的渲染报错 | P0 | [前端页面虽然残缺但不白屏的代码端防御图] |
| TC-EXP-004 | [伪属性嵌套轰炸] | 找到某一个Type | 强行将自己包含的 Attribute 又做父级封装，通过API传递循环引用的环形图谱入参 | Relationship建图引擎拦截到 Cyclic Reference 抛出 400 不接受环形嵌套。 | P0 | [拒绝闭环装载拦截提示快照] |

## 4. 历史大范围防退化 (Regression Focus)
> 被本次开发修改牵连到的老旧大功能面的用例集合点阅。

- 连带回归模块 1：**[原生互动套件集成面]** - 本次五大实体均寄生于 OM Native Entities。由于需要共用核心的 Vote 和 Version 逻辑机制，必须反向拉取 `TC-REG-Glossary-Vote` 及 `TC-REG-Classification-History` 旧域回归考卷，确认底层通用类（如 `EntityRepository`）未被开发因为此资产模块新架构强行加补丁而玷污破坏。
- 连带回归模块 2：**[ElasticSearch 大宽表查询面]** - 全局 SearchBar。验证 Explore 模块旧有其它如 Database, Table, Dashboard 实体的复合查询条件仍能和谐并存，不抛不识别的 Mapping 错乱。

## 5. 性能安全与非功能硬性验证 (Non-Functional)
- [安全防御检查] 对 DataAsset 的 JSONB `extension_data` 输入进行 `<script>alert('pwn')</alert>` Payload 注入。读取与概览渲染时必须转义，严防 DOM 渲染被 XSS 利用。
- [性能体验监控] 分页拉取带有 50 种不同零碎属性模板生成的资产详情大宽表时，要求 API Backend 返回 RT < 800ms，以防动态构建过程压垮服务端内存。
