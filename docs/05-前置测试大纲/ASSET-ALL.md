## 3. 必考题：逆向与健壮性防护 (Boundary & Exception)
> 以“墨菲定律”测试开发在底层图谱结构中对灾难抛掷、身份非法注入及死锁控制是否有实质性的编码保护机制。

| 用例编号 | 取材出处 | 破坏场景 | Given | When (极限操作/越界操作) | Then (防御预期) | 实机截图凭证要求 |
|:---|:---|:---|:---|:---|:---|:---|
| TC-101 | ASSET-001 | **树桩摧毁防御：被保护的根目录剔除** | 创建了一个 D1（目录），其名下绑定驻扎了一台业务资产 DAsset-1 | 操作前端发起抹除 D1 | 返回 409 Conflict。并且抛出包含“检测到仍有关联绑定残”中文警示框，实体绝对完好。 | [带特定中文防呆警报红提示框抓包] |
| TC-102 | ASSET-002 | **字典篡位：修改被占用中的属性名** | 某属性A正受到3个 AssetType 挂载作为底座 | 用户执意去编辑页面篡改属性A的返回名或数据类型 (`data_type`) | 系统接口报错拦截，禁止修改基础数据类型的纲领防止旧资产集体崩坏。 | [因占用阻止强更数据的提示弹幕截图] |
| TC-103 | ASSET-003 | **JSON Extension 越权阻断门** | `telephone` 字段设定 `editor_roles=[\"Role-Admin\"]` | 使用普通消费者账号去抓包拿到后端接口和修改 payload | 系统 API 坚决拒绝并响应 403 Forbidden，禁止对越权 JSON 子路径做局部 PATCH 变更。 | [精准越权提示截报图与终端 403 记录] |
| TC-104 | ASSET-004 | **搜索引擎高负荷级联过滤** | ES与系统连接良好。树形结构层叠高达10层(A->B...->J)，挂载资产3万条。 | 用户点上角A查询，并连续狂点下面的B、C勾选框。前端发生高频重绘防抖考验。 | 前端的勾选不会让系统因超大深度的级联 AND/OR 死查询变昏迷。列表在1.5s内响应且搜索框仍保持高可用交互。 | [包含级联勾选且左下角有Loading罩的画面] |
