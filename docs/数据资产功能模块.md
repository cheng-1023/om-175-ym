# 数据资产功能模块需求规格说明书
## 1. 引言
本文档定义了基于OpenMetadata现有框架新增“数据资产”功能模块的详细需求。旨在通过构建资产分类、目录、类型及属性体系，实现对数据资产的规范化管理与展示。
## 2. 后端需求
### 2.1 实体模型设计
#### 2.1.1 资产分类与资产目录
*   **实体定义**：新增 `AssetCategory`（资产分类）和 `AssetCatalog`（资产目录）实体。
*   **结构关系**：
    *   资产分类为根节点。
    *   资产分类下可配置多个资产目录，资产目录支持多级子目录，形成完整的树形结构。
    *   `DataAsset`（数据资产）实体可划分至具体的资产目录下。
*   **字段要求**：
    *   `level`：层级字段，表示资产目录层级（从1开始），该字段不可修改。
    *   `order`：顺序字段，表示目录排序，该字段支持修改。
*   **业务逻辑**：
    *   **目录删除**：执行级联删除资产目录前，需校验该目录及其子目录下是否包含数据资产。若存在数据资产，则禁止删除。
    *   **批量操作**：支持通过导出和导入功能，批量维护资产分类下的资产目录结构。
#### 2.1.2 资产类型与资产属性
*   **实体定义**：新增 `AssetType`（资产类型）和 `AssetAttribute`（资产属性）实体。
*   **结构关系**：
    *   一个资产类型可关联多个资产属性。
    *   不同资产类型可复用同一个资产属性。
*   **资产属性字段要求**：
    *   `属性分类`：枚举类型，支持通过自定义属性配置可选列表，初始值为：基本信息，技术信息，业务信息，质量信息，安全信息。
    *   `数据类型`：枚举类型，支持通过自定义属性配置可选列表，初始值为：字符串，数值，日期，布尔，文本，数组。
    *   `填写人员`：支持选择多个角色，仅被选中的角色拥有修改该资产属性的权限。
    *   `是否必填`：布尔类型（注：暂无需实现必填字段校验功能）。
*   **业务逻辑**：
    *   支持通过资产类型的导出和导入功能，批量维护资产类型下的资产属性配置。
    *   支持通过资产属性的导出和导入功能，批量维护资产属性信息。
#### 2.1.3 数据资产
*   **实体定义**：新增 `DataAsset`（数据资产）实体。
*   **字段要求**：
    *   `资产目录`：非必填，为空表示未划分至任何目录。
    *   `资产类型`：必填。
    *   `扩展字段`：根据关联的资产类型下的资产属性定义，动态决定该数据资产包含的字段。
*   **业务逻辑**：
    *   支持批量导出和导入数据资产。

#### 2.1.4 公共功能

- 新增的五类实体均需支持通过原框架实现点赞、点踩、版本历史、活动信息流功能。
- 新增的五类实体均无需支持逻辑删除功能。

## 3. 前端需求
### 3.1 总体设计
*   **样式规范**：新增页面需与OpenMetadata原有页面风格保持一致。
*   **导航菜单**：在主页左侧侧边栏新增“数据资产”菜单，包含以下子菜单项：
    *   概览
    *   资产目录
    *   资产类型
    *   资产属性
    *   数据资产
*   **详情页面**：在新增以上菜单的同时还需要增加几个详情页面：
    *   资产目录详情
    *   资产属性详情
    *   数据资产详情
### 3.2 页面功能详细设计
#### 3.2.1 概览
*   **布局与样式参照**：参照“探索（Explore）”页面。
*   **左侧面板**：
    *   展示资产分类和资产目录树。
    *   支持目录树的展开与折叠。
    *   **交互逻辑**：点击目录节点时，联动查询并展示该目录及其子目录下的所有数据资产。
*   **右侧面板**：分为上下两部分。
    *   **上方搜索区**：
        *   默认支持通过资产类型查询。
        *   支持高级搜索功能，参考“探索”页面的高级搜索功能，使用具有 and/or 条件的语法编辑器筛选查询。
    *   **下方内容区**：分为左右两部分。
        *   **左侧列表**：仅展示 `DataAsset` 实体列表（不展示其他实体）。
        *   **交互**：点击数据资产名称，跳转至该数据资产详情页面。
        *   **右侧概览**：展示当前选中的数据资产概览信息。
#### 3.2.2 资产目录
*   **布局与样式参照**：参照“术语库”页面。
*   **左侧面板**：展示资产分类`AssetCategory`列表，有“添加资产分类”按钮。
*   **右侧面板**：展示资产分类详情页。
    *   右上方有“添加资产目录”、“Up Vote”、“Down Vote”、“版本历史”和“...”（管理资产分类）按钮。
    *   “...”按钮中包含导出（以CSV文件格式导出下载所有资产目录，并可与团队共享）、导入（通过上传CSV文件批量维护资产目录，节约时间并提高效率）、重命名（修改资产分类的名称和显示名）和删除（删除此资产分类将永久删除其元数据）按钮，删除需输入**DELETE**进行确认。
    *   包含“资产目录”和“活动信息流”Tab页。
    *   “资产目录”tab页中需要参考术语库页面中的“术语”tab页中实现对应功能：
        *   编辑描述
        *   请求更新描述
        *   列出对话
        *   批量编辑资产分类下的资产目录
        *   全部展开/全部折叠资产目录树
        *   添加目录
        *   编辑目录
        *   移动目录
    *   “活动信息流”Tab页中直接复制术语库页面中的“活动信息流”tab页即可。
    *   **交互**：点击资产目录名称，跳转至该资产目录详情页面。
#### 3.2.3 资产类型
*   **布局参照**：参照“分类”页面。
*   **左侧面板**：展示资产类型`AssetType`列表，有“添加资产类型”按钮。
*   **右侧面板**：展示资产类型详情，包含以下要素：
    1.  右上方设有“添加资产属性”、“Up Vote”、“Down Vote”、“版本历史”和“...”（管理资产类型）按钮。
    2.  下方由多个“属性分类”Tab页+“活动信息流”Tab页组成，“属性分类”tab页需要动态生成。
        *   *示例*：若有属性分类为“基本信息”和“业务信息”的资产属性，则Tab页为“基本信息”，“业务信息”，“活动信息流”。
    3.  “属性分类”Tab页内以列表形式展示属于该分类的资产属性`AssetType`，每个资产属性有修改和删除按钮。
    4.  **交互**：点击属性名称，跳转至该资产属性的详情页面。
#### 3.2.4 资产属性
*   **布局参照**：参照“自定义属性”页面。
*   **页面结构**：分为上下两部分。
    *   **上方功能区**：
        *   包含搜索框（支持按名称、显示名称或描述搜索），属性分类筛选框；
        *   包含“添加资产属性”、“导入”、“导出”按钮，支持批量操作。
    *   **下方列表区**：
        *   展示所有资产属性`AssetType`，每条记录支持修改和删除操作。
        *   名称支持超链接跳转，点击后跳转到该资产属性的详情页面；
#### 3.2.5 数据资产
*   **布局参照**：参照“自定义属性”页面。
*   **页面结构**：分为上下两部分。
    *   **上方功能区**：
        *   包含搜索框（支持按名称、显示名称或描述搜索），资产类型筛选框，资产目录筛选框。
        *   包含“添加资产”、“导入”、“导出”按钮，支持批量操作。
    *   **下方列表区**：展示所有数据资产`DataAsset`，每条记录支持修改和删除操作。

#### 3.2.6 资产目录详情

- **布局参照**：参照“术语”详情页面。
- **页面结构**：分为上下两部分。
  - **上方功能区**：
    - 左侧展示显示名称和名称。
    - 右侧“添加”、“Up Vote”、“Down Vote”、“版本历史”和“...”（管理资产目录）按钮。
    - 点击“添加”按钮后下拉展开“资产目录”和“数据资产”：“资产目录”在当前资产目录下添加资产目录；“数据资产”：在当前资产目录下绑定数据资产。
    - “...”按钮中包含重命名（修改资产目录的名称和显示名）、更改父级目录（通过更改父目录来修改层级结构）和删除（删除此资产目录将永久删除其元数据）按钮，删除需输入**DELETE**进行确认。
  - **下方内容区**：
    - 有“概览”、“资产目录”、“数据资产”、“活动信息流”tab页。
    - “概览”展示该资产目录所有信息。
    - “资产目录”参考术语库页面中的“术语”tab页中实现对应功能：
      *   编辑描述
      *   请求更新描述
      *   列出对话
      *   批量编辑资产分类下的资产目录
      *   全部展开/全部折叠资产目录树
      *   添加目录
      *   编辑目录
      *   移动目录
    - “数据资产”列表展示该目录及其子目录下绑定的数据资产；
    - “活动信息流”直接复制术语库页面中的“活动信息流”tab页即可。

#### 3.2.7 资产属性详情

- **布局参照**：参照“标签”详情页面。
- **页面结构**：分为上下两部分。
  - **上方功能区**：
    - 左侧展示显示名称和名称。
    - 右侧“Up Vote”、“Down Vote”、“版本历史”和“...”（管理资产属性）按钮。
    - “...”按钮中包含重命名（修改资产目录的名称和显示名）和删除（删除此资产目录将永久删除其元数据）按钮，删除需输入**DELETE**进行确认。
  - **下方内容区**：
    - 有“概览”、“活动信息流”tab页。
    - “概览”展示该资产目录所有信息。
    - “活动信息流”直接复制术语库页面中的“活动信息流”tab页即可。

#### 3.2.8 数据资产详情

- **布局参照**：参照“术语”详情页面。
- **页面结构**：分为上下两部分。
  - **上方功能区**：
    - 左侧展示显示名称和名称。
    - 右侧“Up Vote”、“Down Vote”、“版本历史”和“...”（管理资产目录）按钮。
    - “...”按钮中包含重命名（修改资产目录的名称和显示名）和删除（删除此资产目录将永久删除其元数据）按钮，删除需输入**DELETE**进行确认。
  - **下方内容区**：
    - 由多个“属性分类”Tab页+“活动信息流”Tab页组成，“属性分类”tab页需要动态生成。
      - *示例*：若该资产的资产类型中包含有属性分类为“基本信息”和“业务信息”的资产属性，则Tab页为“基本信息”，“业务信息”，“活动信息流”。
    - “属性分类”Tab页内以列表形式展示属于该分类的所有资产属性的键和值，每个资产属性都支持修改值。
    - “活动信息流”直接复制术语库页面中的“活动信息流”tab页即可。

## 4. 功能开发规范
### 4.1 代码目录结构
新增文件需遵循项目架构规范，统一在对应目录下创建 `asset` 目录，并将所有相关文件存放于该目录下。
### 4.2 国际化要求
新增功能必须支持中文和英文，其他语言不做要求。
### 4.3 elasticsearch搜索
新增的实体都需要创建elasticsearch索引，并支持搜索功能。
