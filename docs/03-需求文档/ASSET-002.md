# 需求文档：ASSET-002 资产类型与资产属性

## 1. 实体模型设计 (后端需求)
### 1.1 资产类型与资产属性
- **实体定义**：新增 `AssetType`（资产类型）和 `AssetAttribute`（资产属性）实体。
- **结构关系**：
  - 一个资产类型可关联多个资产属性。
  - 不同资产类型可复用同一个资产属性。
- **资产属性字段要求**：
  - `属性分类`：枚举类型，支持通过自定义属性配置可选列表，初始值为：基本信息，技术信息，业务信息，质量信息，安全信息。
  - `数据类型`：枚举类型，支持通过自定义属性配置可选列表，初始值为：字符串，数值，日期，布尔，文本，数组。
  - `填写人员`：支持选择多个角色，仅被选中的角色拥有修改该资产属性的权限。
  - `是否必填`：布尔类型（注：暂无需实现必填字段校验功能）。
- **业务逻辑**：
  - 支持通过资产类型的导出和导入功能，批量维护资产类型下的资产属性配置。
  - 支持通过资产属性的导出和导入功能，批量维护资产属性信息。

## 2. 页面功能详细设计 (前端需求)

### 2.1 整体导航设计
- 在主页左侧侧边栏新增“数据资产”菜单。提供子菜单：“资产类型”与“资产属性”。

### 2.2 资产属性 (参考 3.2.4)
- **布局参照**：参照“自定义属性”页面。
- **页面结构**：分为上下两部分。
  - **上方功能区**：
    - 包含搜索框（支持按名称、显示名称或描述搜索），属性分类筛选框。
    - 包含“添加资产属性”、“导入”、“导出”按钮，支持批量操作。
  - **下方列表区**：
    - 展示所有资产属性 `AssetType` (原文描述，实际可能指 AssetAttribute)，每条记录支持修改和删除操作。
    - 名称支持超链接跳转，点击后跳转到该资产属性的详情页面。

### 2.3 资产属性详情 (参考 3.2.7)
- **布局参照**：参照“标签”详情页面。
- **页面结构**：分为上下两部分。
  - **上方功能区**：
    - 左侧展示显示名称和名称。
    - 右侧“Up Vote”、“Down Vote”、“版本历史”和“...”（管理资产属性）按钮。
    - “...”按钮中包含重命名（修改资产目录的名称和显示名）和删除（删除此资产目录将永久删除其元数据）按钮，**删除需输入 DELETE 进行确认**。
  - **下方内容区**：
    - 包含“概览”、“活动信息流”tab页。
    - “概览”展示该资产目录（此处指资产属性，遵照原文档映射）所有信息。
    - “活动信息流”直接复制术语库页面中的“活动信息流”tab页即可。

### 2.4 资产类型 (参考 3.2.3)
- **布局参照**：参照“分类”页面。
- **左侧面板**：展示资产类型 `AssetType` 列表，有“添加资产类型”按钮。
- **右侧面板**：展示资产类型详情，包含以下要素：
  1. 右上方设有“添加资产属性”、“Up Vote”、“Down Vote”、“版本历史”和“...”（管理资产类型）按钮。
  2. 下方由多个“属性分类”Tab页 + “活动信息流”Tab页组成，“属性分类”tab页需要动态生成。
     - *示例*：若有属性分类为“基本信息”和“业务信息”的资产属性，则Tab页为“基本信息”，“业务信息”，“活动信息流”。
  3. “属性分类”Tab页内以列表形式展示属于该分类的资产属性，每个资产属性有修改和删除按钮。
  4. **交互**：点击属性名称，跳转至该资产属性的详情页面。
