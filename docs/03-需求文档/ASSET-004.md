# 需求文档：ASSET-004 概览页面与搜索

## 1. 页面功能详细设计 (前端需求)
### 1.1 概览入口 (参考 3.2.1)
- **导航菜单**：主页左侧侧边栏新增“数据资产 -> 概览”路由。
- **布局与样式参照**：完全参照“探索（Explore）”页面。

### 1.2 左侧面板交互
- **展示内容**：展示资产分类和资产目录树。
- **交互动作**：支持目录树的展开与折叠。
- **联动逻辑**：点击目录节点时，联动查询并展示**该目录及其子目录下的所有**数据资产。

### 1.3 右侧面板交互
右侧面板分为上下两部分。

- **上方搜索区**：
  - **默认查询**：默认支持通过资产类型查询。
  - **高级搜索**：支持高级搜索功能，参考“探索”页面的高级搜索功能，**必须使用具有 and/or 条件的语法编辑器**筛选查询。

- **下方内容区**：分为左右两部分。
  - **下左列表**：仅展示 `DataAsset` 实体列表（不展示其他实体）。
  - **左列表交互**：点击数据资产名称，跳转至该数据资产详情页面 (对接 3.2.8 需求规格)。
  - **下右概览面板**：展示当前在左侧列表中选中的数据资产的概览预览信息面板。
