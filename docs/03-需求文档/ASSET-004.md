# 需求文档：ASSET-004 概览入口与搜索中心体验

## 1. 需求说明 (Background)
用户需要一个类同于 OM 平台核心 "Explore (探索)" 功能页的主门户，以左树右列的形式提供最高效直观的钻取沉浸式体验窗口。

## 2. 验收标准 (AC, Acceptance Criteria)

### 2.1 整体版面布局架构
- **AC1**：主页左侧栏中的首个“数据资产 -> 概览”项为门户路由标引。**布局与主视觉 100% 参照并复用当前的“探索(Explore)”页面**引擎进行适配。

### 2.2 左侧树形钻取面板
- **AC2**：左侧展示一个结构清晰的分类到目录的两层套嵌聚合折叠树 (TreeView)。
- **AC3 [点击下推过滤交互]**：当用户在树上勾选或点击了某一个“资产目录”节点时，右侧主体面板下方的数据资产记录表格清单，必须自动下推一个级联关联过滤器参数：**约束必须展现所属该目录 (包括其向下递归展开所有底层子目录) 范畴内包裹的所有 `DataAsset` 数组返回。**

### 2.3 右侧高级检索总引擎
- **AC4 [默认检索过滤]**：右侧首屏居中的核心搜索输入条中，必须预置一个针对 `资产类型` 维度的基础筛选项。
- **AC5 [OM 原生语境高级查询器]**：复刻应用高级查询特性栏。拉起的高级搜素生成器 (Advanced Search query builder) 视图组件必须能拼装带有复杂表达式结构的查询语句（AND/OR 套嵌逻辑组条件），由前端解析转换为合适的 ES DSL 后送达 API 查询执行，并正确呈现反显条件芯片集。

### 2.4 右侧视图主工作区大屏呈现
- **AC6**：下方结果展示位进行左右分割，比例合理。
- **AC7**：下层左侧**仅限定**显示命中的 `DataAsset` 粗体简介列表，屏蔽其他体系实体。单击直接越入详情。
- **AC8**：下层右侧是一个响应式的缩略浮层 “当前选中资产概览(Preview)” 区，能够展示所选定的特定高亮列表项 DataAsset 的关键 metadata 属性和基础简介信息，便于使用户免跳出进行快速筛查判断其业务准确度。
