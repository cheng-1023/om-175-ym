# 需求文档：ASSET-003 数据资产

## 1. 实体模型设计 (后端需求)
### 1.1 数据资产实体定义
- **实体定义**：新增 `DataAsset`（数据资产）实体。
- **字段要求**：
  - `资产目录`：非必填，为空表示未划分至任何目录。
  - `资产类型`：必填。
  - `扩展字段`：根据关联的资产类型下的资产属性定义，动态决定该数据资产包含的字段。
- **业务逻辑**：
  - 支持批量导出和导入数据资产。

## 2. 页面功能详细设计 (前端需求)

### 2.1 整体导航设计
- 在主页左侧侧边栏新增“数据资产”菜单。提供子菜单：“数据资产”。

### 2.2 数据资产列表页 (参考 3.2.5)
- **布局参照**：参照“自定义属性”页面。
- **页面结构**：分为上下两部分。
  - **上方功能区**：
    - 包含搜索框（支持按名称、显示名称或描述搜索），资产类型筛选框，资产目录筛选框。
    - 包含“添加资产”、“导入”、“导出”按钮，支持批量操作。
  - **下方列表区**：
    - 展示所有数据资产 `DataAsset`，每条记录支持修改和删除操作。

### 2.3 数据资产详情页 (参考 3.2.8)
- **布局参照**：参照“术语”详情页面。
- **页面结构**：分为上下两部分。
  - **上方功能区**：
    - 左侧展示显示名称和名称。
    - 右侧具备“Up Vote”、“Down Vote”、“版本历史”和“...”（管理资产目录/实体）按钮。
    - “...”按钮中包含重命名（修改资产目录的名称和显示名）和删除（删除此资产目录将永久删除其元数据）按钮，**删除需输入 DELETE 进行确认**。
  - **下方内容区**：
    - 由多个“属性分类”Tab页 + “活动信息流”Tab页组成，“属性分类”tab页**需要动态生成**。
      - *示例*：若该资产的资产类型中包含有属性分类为“基本信息”和“业务信息”的资产属性，则Tab页为“基本信息”，“业务信息”，“活动信息流”。
    - “属性分类”Tab页内以**列表形式展示属于该分类的所有资产属性的键和值**，每个资产属性都支持修改值。
      - *约束补充(继承2.1.2)*：仅当当前用户具备“填写人员”限定的角色权限时，才允许对该扩展属性值进行修改。
    - “活动信息流”直接复制术语库页面中的“活动信息流”tab页即可。
