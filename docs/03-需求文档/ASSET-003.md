# 需求文档：ASSET-003 数据资产建设与详情管理

## 1. 需求说明 (Background)
`DataAsset` 是资产框架核心的承载实例。它是一个最终被定级为某一种“类型”下、且归置到某一个“目录”文件夹下的数据档案实体。它具备根据类型推导得到的动态录入表单特征。

## 2. 模块：后端支持
### 2.1 功能描述
构建 `DataAsset` 模型库及其基于类型的动态特征提取落库解析能力。
### 2.2 验收标准 (AC)
- **AC1**：支持落库管理 `DataAsset` 实体记录，必须关联必填项 `资产类型 [FK: AssetType]`，可选关联父级容器 `资产目录 [FK: AssetCatalog]`。如果目录为空，视为游离悬空状态（未编排）。
- **AC2**：必须支持将具体的 `扩展字段值池` 保存入 `扩展字段 (extension)` 的 JSONb 或动态映射容器内。
- **AC3**：批量上报上传时，支持 CSV 或 JSON 文件进行大规模 `DataAsset` 结构导出及回盘导入。

## 3. 模块：前端页面展示
### 3.1 数据资产汇总列表页
#### 3.1.1 功能描述
大底盘列表展厅。**布局参照“自定义属性 (Custom Properties)”页面。**
#### 3.1.2 验收标准 (AC)
- **AC1**：作为左侧最后一个“数据资产 -> 数据资产”菜单，提供全局展台呈现。
- **AC2**：页面上方提供三套维度的横向联合筛选头：常规搜索槽 / 资产类型下拉联动框 / 资产分类-目录级联筛选框。
- **AC3**：操作区带有“添加资产”（直接点击打开向导创建新的、绑定于某个类型的资产实例配置流程）与批量管理（Import/Export）。
- **AC4**：底端的主表格，展示 `DataAsset` 基本信息，提供每条记录的单独操作编辑和快速物理删除入口。支持名称点击超链跨入详情看图空间。

### 3.2 数据资产详情页 (重要)
#### 3.2.1 功能描述
终端浏览视图，将动态聚合类型表单及真实填写的值呈献给最终用户。**布局参照“术语(Term)” 或其它核心探索详情页面。**
#### 3.2.2 验收标准 (AC)
- **AC1**：基本信息顶置：displayName / Name 与四套基底操作（Up/Down/Version/More(Rename|Delete)）。
- **AC2**：主体下部呈现动态 `分类Tab`：需要读取当前 DataAsset 所属的 AssetType 配置，同样采用 **AC所见即分类** 原则渲染并行的分类 Tab 连同“活动信息流”Tab。
- **AC3 [修改鉴权约束]**：对于 Tab 下陈列的一排排具体的键和值对（如：“系统拥有者：张三”），编辑动作的可用性必须受限于权限。**如果该属性上的 `填写人员` Role 清单中有设置，则只有具备相应前端 Role 角色的请求者，才被允许点击该项的值编辑图标及调出对应修改保存控件。否则仅可供查阅。**
