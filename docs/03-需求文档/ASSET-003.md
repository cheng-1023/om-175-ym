## 2. 需求说明

### 2.1 现状
企业数据资产分散在各处，缺乏一个统一的最终落地台账视图，且无法根据不同的“类型模板”展示出动态的采集扩展字段表单数据。

### 2.2 目标
构筑最核心的数据资产（DataAsset）实例实体及其上下游挂靠关系（目录/类型）闭环，并在前端以详情动态 Tab 和表单编辑能力作真实输出。

### 2.3 范围
- **包含**：`DataAsset` 实体的落库和 JSON 扩展结构体保存。前端概览台账表呈现及其包含特定权限要求的详细动态 Tab 面板。
- **不包含**：ES引擎的查询联动（在 ASSET-004 概览专门讲）。

## 3. 需求内容

### 3.1 功能需求

#### 3.1.1 功能列表

| 功能点编号 | 功能名称 | 优先级(MoSCoW) | 简要说明 |
| :--- | :--- | :--- | :--- |
| F-001 | 数据资产实例底座 | Must Have | 承载基础与自定义元数据集群的数据总线表。 |
| F-002 | 前端统一数据列表 | Must Have | 提供跨库跨种类的多栏过滤筛选检索区界面。 |
| F-003 | 前台动态数据填充与鉴权 | Must Have | 通过引用的资产类型生成对应的填报界面，实施填写角色管控门禁。 |

#### 3.1.2 功能详情 (基于 User Story)

**[F-001] 数据资产实例底座**
- **业务目标**：完成最终数据对象的收录归口。
- **业务规则**：单条 `DataAsset` 能够游离悬空（资产目录留空），但必须强制指定归属某一模板组（必填 `资产类型`）。`扩展字段` 对应的值通过 JSON/JSONB 等无绑定形式灵活写入。
- **输入/输出条件**：
  - 支持 CSV 批量文件作为导出导入的双端介质。

**[F-002] 数据资产视图罗列区 (参考 3.2.5)**
- **业务目标**：导航台账底盘大展示。
- **交互界面描述**：**参照原“自定义属性(Custom Properties)”页面**底色。设置：上查询下列表双拼结构。上方工具行包含三大核心过滤器：搜索栏/类型选择/分类目录级联。以及附设添加、导出的业务键。名称支持超级链接连至核心页面。

**[F-003] 数据资产详情编辑台 (参考 3.2.8)**
- **业务目标**：终端阅读与采编编辑。
- **交互界面描述**：**参照原“术语(Term)”页的深邃详情面板布局**。页头保持左右分布，包含常规的版本及“删除要输入 DELETE 校验”规范。
- **动态解析与填写授权**：进入下辖内容区时，页面依据数据资产携带的 `资产类型` 引线，将其所属的分类抽提出形成多 Tab 分散页（含活动流）。切换某个 Tab，里头按键值对竖向或宫格展开各扩展属性，并附带针对单个字段的保存更改控件。
- **重点底线**：**如果该展示字段（基底属性）设定了 `填写人员` Role 限流阀，则前端编辑铅笔按钮的隐现及接口调用皆必须在此处受到调用者系统当前角色的身份核验隔离。**只有具备相关角色白名单认证的人能够对其扩展值修改写入库内。

### 3.2 非功能需求

- **性能需求**：海量数据资产列表分页查询需要在 500ms 内回包稳定返回。

## 4. 验收标准

### 4.1 验收标准 (Acceptance Criteria)
> 🚨【重要红线】这里是 QA 进行“测试左移”出题和“开发者自测”的唯一来源！每一条必须是非主观的、可被机器或人明确验证的条件。

- [ ] AC-01: **(实例生命合规度)** 创建某个 `DataAsset` 时，系统应当容忍“资产目录”未勾选，但绝不放行“资产类型”缺省的保存动作请求。
- [ ] AC-02: **(动态视图渲染)** 对于特定引线的资产，详情下方必定能准确罗列出依据其背负“类型模板”聚合派生的各类 Tab 控制器标签及内文项配置格。
- [ ] AC-03: **(身份提权保护器拦截验证)** 使用账户 A (无预设 Role )进入一个属性（如：拥有者/电话）查看其 `DataAsset` 详情，该值旁边应隐藏或禁用编辑组件并锁死无法抓包修改；切换拥有对应修改 Role 授权的账户 B 再次访问，必须允许其触发并在保存后落库重显。
- [ ] AC-04: **(版面布局对照)** 列表页完全遵循了给定的上部包含三个明确点名过滤器（名称/类型/目录）的 “自定义属性” 界面风格。

### 4.2 验收测试方案

| 测试场景 | 前置条件 | 操作步骤 | 预期结果 |
| :--- | :--- | :--- | :--- |
| 定向填报角色控制排查 | 定义一个仅允许 Admin 填写的属性字段并下发到某实体实例记录中 | 1. 登录非 Admin 职级账户；2. 定位到该具体的数据资产详情对应的分类页签下的那条字段 | 观察并确认编辑标识置灰/丢失/后端提示越权，无法发生涂改覆盖。 |
