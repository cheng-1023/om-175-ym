# 需求文档：ASSET-001 资产分类与资产目录

## 1. 实体模型设计 (后端需求)
### 1.1 资产分类与资产目录
- **实体定义**：新增 `AssetCategory`（资产分类）和 `AssetCatalog`（资产目录）实体。
- **结构关系**：
  - 资产分类为根节点。
  - 资产分类下可配置多个资产目录，资产目录支持多级子目录，形成完整的树形结构。
  - `DataAsset`（数据资产）实体可划分至具体的资产目录下。
- **字段要求**：
  - `level`：层级字段，表示资产目录层级（从1开始），**该字段不可修改**。
  - `order`：顺序字段，表示目录排序，**该字段支持修改**。
- **业务逻辑**：
  - **目录删除**：执行级联删除资产目录前，需校验该目录及其子目录下是否包含数据资产。若存在数据资产，则禁止删除。
  - **批量操作**：支持通过导出和导入功能，批量维护资产分类下的资产目录结构。

## 2. 页面功能详细设计 (前端需求)
### 2.1 整体导航设计
- 在主页左侧侧边栏新增“数据资产”菜单。提供子菜单：“资产目录”。

### 2.2 资产目录概览/资产分类展示 (参照：3.2.2 资产目录)
- **布局与样式参照**：参照“术语库”页面。
- **左侧面板**：展示资产分类 `AssetCategory` 列表，有“添加资产分类”按钮。
- **右侧面板**：展示资产分类详情页。
  - **右上方按钮区**：包含“添加资产目录”、“Up Vote”、“Down Vote”、“版本历史”和“...”（管理资产分类）按钮。
  - **“...”下拉菜单操作**：
    - **导出**：以CSV文件格式导出下载所有资产目录，并可与团队共享。
    - **导入**：通过上传CSV文件批量维护资产目录，节约时间并提高效率。
    - **重命名**：修改资产分类的名称和显示名。
    - **删除**：删除此资产分类将永久删除其元数据，**删除需输入 DELETE 进行确认**。
  - **下放多 Tab 页**：包含“资产目录”和“活动信息流”Tab页。
    - **“资产目录”Tab页**：必须全量参考术语库页面中的“术语”tab页实现以下功能：
      - 编辑描述
      - 请求更新描述
      - 列出对话
      - 批量编辑资产分类下的资产目录
      - 全部展开/全部折叠资产目录树
      - 添加目录
      - 编辑目录
      - 移动目录
    - **“活动信息流”Tab页**：直接复制术语库页面中的“活动信息流”tab页。
  - **交互要求**：点击资产目录名称，跳转至该资产目录详情页面。

### 2.3 资产目录详情页 (参照：3.2.6 资产目录详情)
- **布局参照**：参照“术语”详情页面。
- **页面结构**：分为上下两部分。
  - **上方功能区**：
    - **左侧**：展示显示名称和名称。
    - **右侧**：“添加”、“Up Vote”、“Down Vote”、“版本历史”和“...”（管理资产目录）按钮。
    - **“添加”下拉动作**：点击“添加”按钮后下拉展开“资产目录”和“数据资产”。
      - “资产目录”：在当前资产目录下添加资产目录。
      - “数据资产”：在当前资产目录下绑定数据资产。
    - **“...”下拉菜单动作**：包含重命名（修改资产目录的名称和显示名）、更改父级目录（通过更改父目录来修改层级结构）和删除（删除此资产目录将永久删除其元数据）按钮，**删除需输入 DELETE 进行确认**。
  - **下方内容区**：
    - 包含“概览”、“资产目录”、“数据资产”、“活动信息流”tab页。
    - **概览**：展示该资产目录所有信息。
    - **资产目录**：参考术语库页面中的“术语”tab页中实现对应功能（包括：编辑描述、请求更新描述、列出对话、批量编辑资产分类下的资产目录、全部展开/全部折叠资产目录树、添加目录、编辑目录、移动目录）。
    - **数据资产**：列表展示**该目录及其子目录下绑定的数据资产**。
    - **活动信息流**：直接复制术语库页面中的“活动信息流”tab页即可。
